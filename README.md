# Energy Bill Analytics

## Overview

This project analyzes residential electricity bills from July 2024, 2025 and 2026 using Python.

The objective is to transform electricity bills into a structured dataset and perform exploratory data analysis, calculate indicators and create visualizations that support data-driven interpretation.

## Dataset

The dataset was manually created from three residential electricity bills issued in July of:

- 2024
- 2025
- 2026

## Technologies

- Python
- Pandas
- Matplotlib
- Google Colab

## Project Structure

- Data import
- Exploratory Data Analysis (EDA)
- Indicator analysis
- Data visualization
- Conclusions and insights
